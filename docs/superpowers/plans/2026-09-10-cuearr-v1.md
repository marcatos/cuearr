# Cuearr v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Cuearr v1 — a Go *arr daemon that watches folders / accepts Lidarr hooks, splits lossless image+CUE into per-track files via shntool, exposes an authenticated embedded UI/API, and publishes binaries plus Docker/compose/Helm/Proxmox/Unraid packaging on public GitHub with Issues as the tracker.

**Architecture:** Single Go binary with hexagonal packages (`domain` → `app` → `ports` ← `adapters`). Default splitter shells out to `shntool`/`cuetools`; native splitter is a stub. SQLite stores jobs/settings. `go:embed` serves the web UI. CI releases multi-arch binaries and a tool-equipped container image.

**Tech Stack:** Go 1.23+, `modernc.org/sqlite` (or `mattn/go-sqlite3` only if CGO accepted in Docker), `gopkg.in/yaml.v3`, `golang.org/x/crypto/bcrypt`, `github.com/coreos/go-oidc/v3`, `golang.org/x/oauth2`, fsnotify, GitHub Actions, Docker Buildx, Helm 3.

**Spec:** `docs/superpowers/specs/2026-09-10-cuearr-design.md`

## Global Constraints

- License: MIT; never commit secrets or copyrighted audio
- Tracker: GitHub Issues only (templates + labels); no Plane for this repo
- Hexagonal: domain has zero IO; split via `ports.Splitter`
- Default engine: shntool shell-out; native engine returns `ErrNotImplemented` behind setting `engine: shntool|native`
- Auth v1: password session + API key header `X-Api-Key` + OIDC
- Binaries: linux/amd64, linux/arm64, darwin/amd64, darwin/arm64, windows/amd64
- Logs: leveled, timed steps, no secrets; job states `queued|running|completed|failed`
- Conventional Commits; atomic commits per task
- Personal GitHub: `marcatos/cuearr` public (`gh` account `marcatos`)
- CI synthetic fixtures only (generate tiny FLAC in tests)

package logging

import (
  "log/slog"
  "os"

)

func New(level string) *slog.Logger {
  var lv slog.Level
  switch strings.ToLower(level) {
  case "debug":
    lv = slog.LevelDebug
  case "warn":
    lv = slog.LevelWarn
  case "error":
    lv = slog.LevelError
  default:
    lv = slog.LevelInfo
  }
  return slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: lv}))
}
